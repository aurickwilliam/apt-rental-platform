# Batch 3 private-media auth and retry fixes

Batch 3 binds private signed-URL caching to the authenticated identity, unifies application-document signing, and routes chat media failures through one retry path. Equivalent document inputs now retain a stable resolution identity, and C5 apartment-image behavior remains deferred without a contract change.

## High-level view

A pre-transition signing request cannot populate the post-transition cache because the resolver only writes results that match the current cache generation. The process-lifetime auth listener establishes the identity on restoration and clears private-media state on each real account transition.

Tenant and landlord document flows now share the resolver while retaining document rows and their `{ label, path, signedUrl }` surface. The document hook derives its effect identity from values rather than the caller’s array reference.

Video playback errors cross one guarded handoff into the chat attachment retry flow, while C5 remains outside this diff. Focused validation passed: 4 suites and 11 tests.
